# 여행 일본어 회화 · Jap_Con

『どんどん話せる！日本語会話フレーズ大特訓 必須700』(700 Essential Phrases for Japanese Conversation) 1~92과를 한국어로 정리한 인터랙티브 학습 사이트입니다. 일본 여행에서 바로 쓸 수 있도록 ✈ 여행 필수 과를 표시했습니다.

- **메인 페이지**: `index.html` — 92개 과 카드, 검색(과 번호·한국어), ✈ 여행 필수/미완료 필터, 학습 진도, 추천 학습 순서
- **과 페이지**: `Lesson1/` ~ `Lesson92/` — 핵심 표현(후리가나·로마자·한국어 뜻·해설), 소리 듣기(TTS), 연습문제 5종, 채점(점수·정답·해설)
- **연습문제 5종**: ① 뜻 고르기 ② 일본어 고르기 ③ 빈칸 채우기 ④ 듣고 고르기 ⑤ 직접 쓰기(히라가나·로마자 입력, 장음 누락은 0.5점) — 총 약 2,800문항
- 92과는 교재 맨 끝의 **필수 표현 70**이며, 각 표현에서 해당 과로 이동할 수 있습니다.
- 후리가나/로마자 표시, 느리게 듣기 설정과 학습 기록은 브라우저(localStorage)에 저장됩니다.

## 사용
GitHub Pages: `https://yalli2.github.io/Jap_Con/`
각 과는 `https://yalli2.github.io/Jap_Con/LessonN/` 형식입니다.

```

assets/style.css      공통 스타일

LessonN/index.html    각 과 데이터(표현·연습문제)
```
